================================================================================
TROUBLESHOOTING
================================================================================

WIDGET NOT APPEARING:
  1. Check browser console (F12) for errors
  2. Verify CSS file loaded (DevTools → Network tab)
  3. Check z-index not overridden by other CSS

API ERRORS:
  1. Verify .env file exists with API key
  2. Run: curl http://localhost:3000/api/health
  3. Check API key is correct at console.anthropic.com
  4. Look for network errors in browser console

CHAT NOT SENDING:
  1. Ensure backend is running
  2. Check message input has text
  3. Verify API endpoint in config
  4. Look for error messages in console

MESSAGES NOT PERSISTING:
  1. Check localStorage is enabled
  2. Verify browser storage quota not exceeded
  3. Try clearing cache and reload
  4. Check privacy/incognito mode

See AI_CHAT_SETUP.md for more details.
