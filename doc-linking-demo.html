How to Implement

Step 1: Include Scripts and Styles

<!-- In HTML head or body -->
<link rel="stylesheet" href="doc-link-modal.html">
<script src="doc-linking.js"></script>

Step 2: Initialize Manager

// In your module's JavaScript
const caseId = '...'; // from URL or app state
const manager = DocumentLinking.initializeDocumentLinking(caseId, 'moduleName');

Step 3: Register Calculations

// Register one or more calculations
manager.registerCalculation({
  id: '[Party A]:w2',
  displayValue: '[amount]',
  description: 'W-2 Base Income ([Party A])',
  category: 'income',
  method: 'Recurring W-2 base salary from primary employment',
  breakdown: [
    { k: 'Annual base', v: '[amount]' },
    { k: 'Monthly', v: '$19,735', tot: true }  ],
  exhibits: [
    {
      name: 'PayStub 41671621',
      kind: 'paystub',
      file: '../pay stubs/PayStub 41671621.pdf',
      payer: 'Employer payroll',
      highlights: [
        { label: 'Base earnings', value: '$9,108.42', ref: 'YTD total' }      ]
    }
  ]
});

Step 4: Make Numbers Clickable

// Method 1: Auto-link all [data-calc-id] elements
DocumentLinking.autoLinkNumbers();

// Method 2: HTML attribute
<div data-calc-id="[Party A]:w2">[amount]</div>

// Method 3: Manual element linking
const el = document.getElementById('myValue');
DocumentLinking.makeNumberClickable(el, '[Party A]:w2');

Step 5: Users Click to View Documents

When users click a linked value, a modal opens showing:

  • The calculation breakdown with component values
  • How the calculation was performed (method)
  • All supporting documents
  • Key highlights and page references
  • Links to view full PDF documents

Key Data Structures

CalculationReference Object

Property Type Description
id string Unique identifier (e.g., '[Party A]:w2')
displayValue string The number shown to user ([amount])
description string What this calculation represents
category string Type: 'income', 'expense', 'asset', 'calculation'
method string How/why it was calculated
breakdown array Component values and steps
exhibits array Supporting documents with metadata

Exhibit Object (Document Reference)

Property Type Description
name string Document name ('PayStub 41671621')
kind string Document type ('paystub', 'form', 'report', 'filing')
file string|null Path to document or null if not available
page string|number Page reference ('1', 'Schedule 2', 'p.6-7')
payer string Document source ('Employer', 'Bank')
highlights array Key data points from document
flag string Warning if data not yet verified

Features

For Users

  • Click any calculated number to see its sources
  • View supporting documents inline
  • See document highlights and key data
  • Navigate to full documents
  • Understand calculation methodology

For Analysts

  • Link calculations to source exhibits programmatically
  • Maintain audit trail of evidence
  • Flag unverified or pending documents
  • Track multiple document sources per calculation
  • Export calculation reference data

Technical Features

  • Lightweight, no external dependencies
  • Dark mode support
  • Mobile responsive
  • Accessible (ARIA labels, keyboard navigation)
  • Fast O(1) lookup for calculations
  • Reusable modal (one instance for all values)

Next Steps

To integrate into your modules:

  1. Copy doc-linking.js and modal CSS to webapp directory
  2. Include scripts in your module HTML files (spousal.html, child-support.html, etc.)
  3. Call initializeDocumentLinking(caseId, moduleName) at module startup
  4. Register all calculations with manager.registerCalculation(...)
  5. Add data-calc-id attributes to your HTML or call autoLinkNumbers()
  6. Test! Click numbers and verify modals display correctly
