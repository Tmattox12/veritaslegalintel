Help & Information

What gets cleared?

  • All uploaded documents
  • All extracted items and transactions
  • All categorization mappings
  • Document statistics and counts
  • Recent uploads list

What doesn't get cleared?

  • Application settings and preferences
  • User interface configuration
  • Sidebar state

When should I reset?

  • Before starting a new test cycle
  • When testing with new sample data
  • After completing a case review
  • To verify fresh upload functionality

💡 Tip: Use "Export Data First" to save your current data before resetting, then you can reload it later if needed.
